# Qwen3.5 benchmark results / 実測結果

RTX 5060 Tiでは、4B・9BともCUDAの方が生成が速く、SYCLの方が最初のトークンを早く返し、VRAM使用量も少なめでした。RTX 3060の4Bでは、speedの生成はCUDAが速く、qualityではSYCLが生成・初応答ともに速く、VRAM使用量も少なめでした。

数値はすべて **SYCL / CUDA** の順です。9Bの推論はRTX 5060 Tiで測定しました。

| GPU | モデル | パック | 生成 (tok/s) | 初応答 (ms) | ピークVRAM増分 (MiB) |
|---|---|---|---:|---:|---:|
| RTX 5060 Ti 16 GiB | 4B | speed | 161.54 / 200.18 | 206.2 / 213.6 | 2,352 / 2,556 |
| RTX 5060 Ti 16 GiB | 4B | quality | 140.44 / 165.23 | 210.2 / 236.0 | 2,706 / 2,930 |
| RTX 5060 Ti 16 GiB | 9B | speed | 102.89 / 117.26 | 305.8 / 328.7 | 3,706 / 3,970 |
| RTX 5060 Ti 16 GiB | 9B | quality | 85.26 / 95.12 | 311.6 / 372.3 | 4,530 / 4,814 |
| RTX 3060 12 GiB | 4B | speed | 114.50 / 119.83 | 367.5 / 365.1 | 2,334 / 2,562 |
| RTX 3060 12 GiB | 4B | quality | 104.18 / 99.45 | 371.7 / 408.5 | 2,708 / 2,936 |

日本語の長文読解は、表の全構成で3問すべて正解でした。算術12問では、4Bは全構成で8問、9B speedは両方10問、9B qualityはSYCLで10問、CUDAで9問正解しました。

## 測定条件

- Windowsネイティブ、2026年11月19日測定。両バックエンドで同じウェイト・BF16 KVを使用。コンテキスト上限2,048、同時リクエスト1件、思考オフ、greedy生成。 [入力と採点基準](../bench/qwen35/)
- 初応答（TTFT）は入力トークンを渡してから最初のトークンが返るまで。生成速度は2トークン目以降。いずれもウォームアップ後、1,072〜1,073トークンの読解3問での中央値。
- ピークVRAM増分は、`nvidia-smi` で測ったGPU全体の使用量のピークと、モデルを読み込む前の使用量との差。
